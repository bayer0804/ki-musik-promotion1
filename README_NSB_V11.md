# Niche Song Bridge v11 Android Chrome Build

Dieser Branch dient nur zum Bauen der Android-APK von Niche Song Bridge v11.

- Quelle: `source.zip`
- Build: GitHub Actions
- Ziel: Debug-APK als Workflow-Artefakt
- Hauptbranch des bestehenden Projekts bleibt unverändert.

Nach erfolgreichem Build findest du unter **Actions > Build Niche Song Bridge APK > Artifacts** das Paket `Niche-Song-Bridge-v11-debug`.
